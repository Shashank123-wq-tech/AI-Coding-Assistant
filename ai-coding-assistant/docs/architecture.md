# Architecture

The AI Coding Assistant consists of:

1. Repository Management
2. Repository Scanning
3. AST Code Intelligence
4. Code Search
5. Code Retrieval
6. LLM Layer
7. Agent Orchestration
8. Tool Execution
9. Patch Generation
10. Patch Application
11. Docker Sandbox
12. Test Execution
13. Error Analysis
14. Git Diff
15. Code Review

The LLM communicates with the repository only through controlled tools.
